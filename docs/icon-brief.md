# 阁楼（Glow）图标设计说明

> 交给外部设计师的 brief。现版图标是一版**能看清、但谈不上设计**的几何线稿，请当作占位图整体替换。
> 目标：一个在 48dp 桌面上有识别度、放在原生桌面或厂商桌面上都不掉价的成品图标。

---

## 1. 产品是什么

**阁楼（Glow）** 是一个人的图像工作台。它自己不出图，把活儿交给用户家里的 Mac mini 上跑着的模型服务；
手机只是一个安静的窗口——提交任务、等待、看图、留下。

- **用户**：一个人。不是团队，没有协作，没有分享到社区。
- **三件事**：一句话出图、拿一张照片精修、多张图合成。
- **气质**：克制、私人、安静。界面上大量留白、低对比、暖中性紫，唯一的"响"是照片本身。
- **名字的两面**：中文「阁楼」是空间——一个只属于自己的、在小镇最高处的小屋；英文「Glow」是光——屋里那盏灯。
  图标要把这两层意思收在一个图形里，或者至少不要跟它们冲突。
- **反例**：不要做成"AI 生成器"的通用图（星芒、闪光、魔术棒、神经网络节点）——这类图标在应用列表里没有任何区分度。

## 2. 现在这版的问题（不用客气）

现在的图形是：紫底 + 白色屋顶折线 + 白色圆角窗框 + 窗内一团暖光。概念方向还站得住，执行是业余的：

- 纯线稿，没有体量与材质，像一个示意图标而不像一个标志；
- 屋顶与窗框两条线粗细相同，重心偏上偏瘦，48dp 下像"一个框顶上有个尖"；
- 暖光只是一团径向渐变，没有光源关系；
- 圆角、线宽、留白都是凑出来的，没有网格依据。

**这些都不用保留。** 概念（阁楼 / 灯）可以留、可以换，判断标准是第 6 节。

## 3. 必须出现的场景

一个图标要交付到 5 个位置，任何一处不成立都会显得没做完：

| 位置 | 尺寸 | 约束 |
|---|---|---|
| 桌面 / 应用抽屉 | 48dp 起，最高 192dp | 自适应图标（前景+背景两层），会被裁成圆形、方形、圆角方、水滴等 |
| 通知栏状态图标 | 24dp，实际显示约 18dp | **纯白、单透明通道**，只保留 alpha；细线在 18dp 会消失 |
| Android 13+ 主题图标 | 同桌面 | **单色剪影**，系统会用自己的配色渲染，不能依赖渐变或双色 |
| 冷启动画面 | 居中约 128dp | 用前景图形 + 品牌底色，与桌面图标连成一次过渡 |
| 通知面板 / 安装器预览 | 24–96dp | 厂商安装器（小米、华为等）会按密度取位图，**必须提供位图** |

## 4. 色彩与风格边界

现有主题色（图标应与之一致，或明确给出更好的替代并说明理由）：

| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌紫 | `#6B4EFF` | 主色、启动底色 |
| 提亮紫 | `#7C61FF` | 背景顶部微提亮 |
| 暖光 | `#FFE3B0` | 唯一的暖色，占比要小（≤8% 面积） |
| 深色模式主色 | `#B9A8FF` | 仅界面用，不必进图标 |

- 紫底 + 小面积暖光是现成的对比关系，可以直接沿用；也欢迎给出更有说服力的方案。
- **不要**用高饱和撞色、发光描边、玻璃拟态、多层阴影——和界面气质不符，48dp 下也会糊。
- 允许扁平、允许有微弱体积（单层内外阴影），但不允许写实照片。

## 5. 技术规格（照着给文件即可）

**画布与安全区**

- 自适应图标画布 **108×108dp**；中心可见区 72dp；**安全区是以 (54,54) 为心、直径 66dp 的圆**。
- 所有笔画、光效都必须落在安全区圆内，否则圆形遮罩会切掉。
- 前景层：透明底，只有图形；背景层：满铺 108×108，不透明（纯色或渐变）。

**线宽下限**

- 任何线条在 **48dp 下的实际宽度 ≥ 2dp**（换算到 108 画布约 ≥ 4.5 单位）。低于这个值在状态栏和小图标里会消失
  ——现版就栽在这，24dp 状态栏图标用 2 单位描边，渲染出来几乎为零。

**交付文件**

```
adaptive/foreground.svg      108×108，透明底，安全区 66dp 圆
adaptive/background.svg      108×108，满铺
adaptive/monochrome.svg      108×108，单色剪影（无渐变、无中间色，系统会替换配色）
statusbar-24dp.svg           24×24，纯白 #FFFFFF，仅靠 alpha 表达形状
raster/ic_launcher.png       48 / 72 / 96 / 144 / 192 五个尺寸（方形背景）
raster/ic_launcher_round.png 同上五个尺寸（圆形背景）
splash/foreground.svg        同 adaptive/foreground，用于启动画面
```

如用位图交付，另附 **1024×1024 PNG** 一张，便于以后生成商店素材。

## 6. 验收标准（请按这个自查）

1. **48dp 下仍然认得出主体**，不是一团色块也不是一堆线。
2. **24dp 单色剪影下仍然认得出主体**（这是最严的一关，先画这个，再上色）。
3. 放在**白色和深色壁纸**上都不脏；对比来自图形本身，不依赖壁纸。
4. 在**圆形、圆角方形、方形**三种遮罩下都不被切边、重心不偏。
5. 与应用列表里的**相机、相册、图片编辑类应用可区分**（别做成第二个相机）。
6. 去掉暖色、只留紫白两色时，图形依然成立。
7. 缩到 **18dp**（状态栏）看得出是同一个形状。

## 7. 可以不要的东西

- 不要字母 G 单独立着（小尺寸会读成"O"或糊掉）。
- 不要中文「阁」字（48dp 下笔画会并在一起）。
- 不要"AI/魔法"通用符号。
- 不要求和界面里的小图标风格统一——桌面图标是独立的一件作品。
