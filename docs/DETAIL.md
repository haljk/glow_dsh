# Glow（阁楼）

在本机画图、改图的工作台。不需要懂任何参数，选一个场景、放素材、写一句白话，剩下的交给它。

所有出图都直接调用局域网里的模型服务，不经过第三方接口。

## 三种用法

打开后第一步先选「你要做什么」：

### ① 写一句话出图

没有任何素材，只想画一张图。写下你想看到的画面，比如「一只戴墨镜的橘猫坐在窗台上晒太阳，下午的光很暖」。

写不出来没关系，点「帮我写详细一点」，本地模型会把它扩成一条模型看得懂的完整描述——补上环境、光线、构图、镜头与画质，并去掉「高质量」「杰作」这类没有信息量的词。

下面那些「电影感」「黄金时刻」「浅景深」的小标签，点一下就加进描述里。

### ② 拿一张照片精修

适合真人照片：换背景、换衣服、换发型、调表情、改光线、去掉路人杂物、抠图换纯色底、老照片修复、证件照换底色。

选一张照片，点一个最接近的预设，再用一句白话补充细节（「背景换成海边日落，衣服换成米色针织衫」）。想用另一张图当新背景或新衣服，就再加第 2 张，并在它下面选「当作新背景」或「当作新衣服」。

**这一档的关键在预设本身**：换背景、换衣服这类操作，最难的不是"改什么"，而是"别把脸也改了"。所以每个预设都带一段固定的话，明确告诉模型只改指定部分，并把其余部分逐个锁住。

**这个"保持不变"清单是跟着预设走的**，不是一句通用套话。每个预设声明它被允许改动哪几项，清单由总表减去这几项生成——否则会出现"换光线"预设一边说改光线、一边说光照不变的自相矛盾。面板上选中预设时会直接写出「会改动：…」，剩下没列的才是被锁住的。

这样处理之后：

- 换背景 → 允许改背景、光照与色调（新背景自带光色），人物身份/表情/发型/姿态/镜头角度仍锁住
- 换光线 → 只允许改光照与色调，其余全锁
- 换表情 → 只允许改表情，连主体句里也不会再出现"保留表情"
- 去掉杂物 → 允许增删物体，因此不再出现"不增加也不删除任何物体"

这是普通用户很难自己写对的，因此做成了预设。

需要说明的是：这种"锁住"是靠提示词约束模型，不是蒙版重绘。人脸身份保持得不错（实测换背景后脸、发型、衣服、姿态都还在），但脸型仍可能有轻微漂移，关键用途请多出几张挑一张。

### 如果你自己就会写指令

改图模式下有一个开关：「直接发我写的完整指令，不套用模板」。打开之后，输入框里那一整段就是全部内容——

- 预设里那段固定的话不会再添上，逐项"保持不变"的清单也不会再添上，角色分配出来的句式也不会再添上。发出去的就是你写的那一段。
- 你写的「图1」「图2」（「第2张」也认）会被换成模型认得的写法，这是记号对应，不会替你补别的话。写了不存在的编号（只有 2 张却写「图9」）会原样保留，系统不会替你编一个模型看不见的引用。
- 打开这个开关时，预设那一排会收起来——留着能点却不起作用更让人困惑。
- 指令空着、或者没加图，都会直接提示，不会退回模板"帮你写一段"。

关掉这个开关，就回到上面说的四段拼装。两种方式都可以随时切换，内容不会丢。

### ③ 多张图合在一起

每张图下面有个下拉，选「这张图用来做什么」：主体、背景、服装、色调与画风、构图与机位、局部细节。

模型不会读心，它只知道「有 2 张图」，不知道哪张该被保留、哪张该被借用。指定用途之后，系统会自动写出一条精确的指令，比如「以图 1 为主体，完整保留其身份与五官；把背景替换为图 2 中的场景」。你也可以点「看看我们会怎么告诉模型」，逐字检查它准备发送的指令。

这个方式下最多 5 张图。多一张参考图就多一份等待，所以选图时先想清楚哪几张真的必要。

**三个场景各记各的草稿**：在三种用法之间切换，写好的描述不会互相覆盖。草稿只在当前页面里，刷新页面会清空。

## 画面尺寸：选比例，不填数字

尺寸不让你算宽高，收成一行摘要，点开才选：

```
1:1 · 推荐 · 1 张 …… 1024×1024 ›
```

- **比例五选一**：1:1（方图）、3:4（竖图）、4:3（横图）、9:16（手机竖屏）、16:9（宽屏）。
- **清晰度三档**：快速（先看效果）；推荐（日常出图，模型就是在这附近训练的）；高清（要放大看细节）。
- **张数**只对"写一句话出图"开放，1 或 2 张；精修和合成固定 1 张。

**加了照片的场景默认「跟随原图」**：输出画面直接采用原图的比例（4:3 的照片还是 4:3，竖屏还是竖屏），你只需要选清晰度。4:5 这类不常见的比例也照原样保留，不会被硬拉到五个标准比例上。想完全自己指定，点开那一行就能切。

比例和清晰度是两件事：**改清晰度不会改掉比例**。

## 常用提示词

常写的那几句可以存下来，**最多 5 条**。

写好后点「把上面这句存为常用」；之后点列表里的任意一条，就会直接填回当前输入框；点右侧 × 删除。

关掉再打开还在。已经存满 5 条时会提示先删一条，而不是悄悄顶掉旧的——刻意设上限，就是为了让这个列表短到能一眼扫完。

## 从剪贴板贴图

改图（精修、合成）的时候，参考图不用先存文件再选，直接贴进来就行。两个入口：

| 入口 | 说明 |
| --- | --- |
| `Ctrl+V` | 直接贴。不申请任何权限，剪贴板里没有图片时它不插手，你原本要粘的文字照常粘 |
| 「从剪贴板粘贴」按钮 | 会问一次权限。被拒绝后提示改用 `Ctrl+V` 或「选择文件」，不会反复弹窗 |

- 贴进来的图和本地选的图**完全一样**：同样能改用途、能预览、能删、编号一样顺着排。
- 一次贴多张会按当前场景的上限取（精修 2 张、合成 5 张），超出的部分会明确告诉你没进来。
- 单张太大、总量太大，**在粘贴那一刻就提示**，不会让你等到提交才失败。
- 网页里复制出来的图常是 webp 等格式，插件会统一转成 PNG 再提交。

## 任务在后台跑，不会被打断

一次出图或带参考图的精修要几分钟。如果这段时间挂在一个网页请求上，切页面、刷新、或者任何一层超时都会让结果白跑。

所以提交之后，任务在插件后台排队执行，页面只是隔几秒问一句「好了吗」：

- **切到别的页面、最小化窗口**：任务继续跑，回来结果还在。
- **刷新页面**：任务继续跑，刷新后自动接上进度。
- **一次提交多个**：自动排队，界面上会显示前面还有几个。
- **没有总时长上限**：排队方式下任务一直跟到出图成功或服务明确报错，不会因为"等太久"被掐断。唯一的例外是**连续约三分钟读不到任务进度**——那说明网络或服务断了，不是任务慢。
- **任务记录留得住**：每条任务都留一份记录（什么时候提交、用的什么描述、尺寸、几张、成没成、图叫什么名字）。**关掉再打开，最近记录还在**。

### 取消：只结束等待，不扔掉结果

| 时机 | 会怎样 |
| --- | --- |
| 还在排队，模型没开始 | 真的取消，任务不会再跑，界面显示「已取消（模型还没开始）」 |
| 已经开始生成 | 停不下来。按了之后只是**不在这儿等了**：它继续做完，**图照常存进作品**，列表里那句会写「跑完照常存进作品」 |
| 已经做完 | 直接告诉你「这个任务已经结束了」 |

服务端不支持中断正在进行的生成，所以第二种情况不是出错、也不是界面故障：你已经花掉的那一轮时间，图还是要给你，不会扔掉。已经做完的任务再点取消，什么也不会变。

### 连不上、或者中途关掉了？

任务不会因为这个被判死。连不上服务约三分钟之后，这条任务会显示「结果待取回」——
意思是**图还在服务端，只是这会儿拿不到**，任务记录里留着它的编号：

- 稍后点那条记录上的「继续取回」，插件会按编号再去问一次，拿到就存进作品。
- 下次打开插件也会自动替这些任务问一遍，不用你记着。
- 只有服务端明确说「没有这个任务了」（含结果超过 7 天），才算真的没了。

## 结果

每张图连同它的描述、尺寸、种子一起存到本地，界面上会显示完整路径。

- **点图放大**：全屏查看，可缩放 1–5 倍逐点检查，翻页键或左右方向键看同批其它图，Esc 关闭，也能直接下载。
- **缩放**：滚轮或 `+` / `-` 键放大到 1–5 倍，双击复位。
- **对比原图**：精修或合成出来的图，点缩略图会**直接进入对比视图**；卡片上「并排对比」「滑动对比」两个按钮并列，想看哪种点哪种。两种看法：
  - **并排对比**：参考图在左，生成结果在右，各自占满一栏，适合整体看改得像不像。
  - **滑动对比**：两张图叠在同一位置，拖动分界线——左边露出参考图、右边露出结果，最容易发现「哪里被悄悄改动了」。分界线只画在照片范围内。
  - 两张图比例不同时，滑动对比以结果为准对齐：结果完整显示，参考图会裁掉一点边缘。这样同一处细节在分界线两侧才对得上。
  - 「只看结果」可以随时切回单张大图；看图器底栏的「并排对比 / 滑动对比 / 只看结果」三个按钮是并列的，一步到位。
- **找不到原图时会说清是哪一种情况**：这张是"写一句话出图"画的、本来就没有原图／原图副本已经被删／设置里关掉了「保留参考图副本」。不会笼统地说一句"无原图"。
- **归档（只是隐藏）**：不想让某些结果一直占着主界面，点「归档」收起来。主列表不再显示它，但**文件不会被删除**。已归档的结果有单独入口，可以「移出归档」或直接删除。这里不设密码——目的是让工作台保持干净，不是保密。
- **按这张的参数重做**：把描述、尺寸、种子一起填回去。注意——**复现需要三者同时相同**，只记住种子是复现不出来的。
- **继续改这张**：直接把它当成下一轮的素材，适合「生成 → 局部改 → 再改」。
- **删除**：会先问一次，并写清会一起删掉这张图、它的描述和几张参考图副本。删了恢复不了。

## 更多设置（一般不用动）

- **保留参考图副本**：默认开着。开着的时候，"这张是怎么改出来的"才能在图上看参考图；关掉能省空间，但之后的图就再也对不上原图了。任务本身留着的那份原图不受这个开关影响。
- **自定义尺寸**：需要精确像素时才用。边长要是 32 的倍数，范围 256–2048；填超了会按比例整体缩小，不会把画面压变形。
- **随机种子**：默认「每次不同」。改成「固定不变」后，只要描述和尺寸也一样，就能生成完全相同的图——用来微调描述时对比效果很有用。
- **想避免的东西**（仅文字生图）：这个模型没有「不要什么」这个通道，写了也会被忽略。所以这里的内容会交给写作助手，改写成正面说法（「不要杂乱」→「背景干净，纯白无缝背景，主体四周留白」）。

## 模型服务（在本页配置）

面板右上角的连接状态胶囊或齿轮都能打开「设置」，点开就能改，改完即时生效，不用重启：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 出图方式 | 后台排队 | 「后台排队」把任务交给队列服务，提交就返回；「直连出图」是旧的同步方式，留作回滚 |
| 队列服务地址 | `http://127.0.0.1:9742` | 排队出图走这里 |
| 模型服务地址（回滚用） | `http://127.0.0.1:9741` | 跑出图模型的那个服务；切回直连时用它，也用来读它支持的尺寸上限 |
| 提示词服务地址 | `http://127.0.0.1:9739` | 写提示词用的本地模型 |
| 模型名 | `default_model` | 该服务只接受这个名字，写别的会报错 |
| 直连出图时一次请求最多等多久 | 1800 秒 | **只对直连出图生效**。排队方式下这一项不起作用：任务在后台排队，没有总时长上限 |
| 图片保存目录 | 用户图片目录下的 `glow` | 留空用默认；换目录等于换整个画廊 |

「测试连接」会分别探一下这几个地址，「保存并生效」才会写入并立刻改用新地址，「恢复默认地址」清掉自定义。

旧版本的设置（只有「出图服务地址」且指向回滚端口）会在首次加载时自动迁移到排队方式，原地址保留为回滚地址，不需要手动改。

这些设置存在你自己电脑上的一个配置目录里，**不在插件目录里**——所以换机器、换仓库都不会把地址带出去，别人安装后自己填即可。

## 已知限制

- **精修不能保证百分百不像换人**。预设里的"锁住其余部分"是通过提示词约束模型实现的，不是蒙版重绘；脸型、发际线仍可能轻微变化。关键用途请一次多出几张挑，或者把改动幅度说小一点。
- 出图服务**同一时刻只能跑一个任务**。连续提交会自动排队，等待时间会累积。界面上的「前面还有几个」和剩余时间是估算值，不是承诺。
- **已经开始生成的任务停不下来**。排队阶段取消是真取消；开跑之后取消只是不再等待，任务会做完、图照常保存——但那一轮算力省不下来。
- **「结果待取回」要靠一次成功的连接才能收尾**。如果一直连不上、或服务端在 7 天里始终没恢复，那份结果最后还是要放弃；插件会保留记录，不会假称已经取回来了。
- 排队方式下服务端**只保留 7 天结果**。插件在任务成功时就把图存到本地目录，所以正常使用不受影响；如果本地目录被清空，服务端那份图 7 天后也取不回来了。
- **小尺寸会严重掉画质**。模型在 1024² 附近训练，太小的图会退化成模糊色块。所以清晰度默认就是「推荐」；选「快速」只适合先看构图。
- 换背景时，**复杂发丝边缘可能出现毛边**；抠纯色底也一样，出图后建议放大看边缘。
- 耗时参考：1024² 纯粹出图约 1 分多；1024² 单图精修约 3–4 分钟；尺寸越大、参考图越多越慢。
- **任务记录不会一直堆下去**：最近记录和更早的记录都有上限，超出时按时间删最旧的；开关里没有一键清空，需要时只能手动删配置目录里的记录文件夹。
- 界面文案为中文。
- **只允许本机访问**：接口会校验请求的目标地址，必须是本机或本服务实际监听的地址，其它一律拒绝。这么做是为了挡住"伪装成本机"的网页偷看你的记录和图片。想从手机或其它设备访问，需要另做一个带正式认证的后端，而不是把这个接口放开。
- 历史记录按保存目录扫描得出，手动删掉图片文件后记录也会消失。
- 早期没有参考图副本的旧图只能单看，无法对比。
