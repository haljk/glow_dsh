## 需要顾问重点看的几处

1. **工作台的信息密度**：一屏里同时有状态、三种玩法、输入、尺寸张数、图库入口，
   底部还有固定操作条。是否过密？场景卡是否有存在必要（还是应该藏进引导）？
2. **场景卡的选中态**：现在用「浅紫底 + 2dp 主色边框」表示选中，与输入框聚焦态的
   紫色边框是否冲突、是否够明显。
3. **三段选择器的位置**：它放在图片下方、操作条上方。手机上是否该收进右上角菜单，
   把整个下沿留给照片。
4. **查看器的黑白比例**：方形图在 411dp 宽的屏上有约 373px 上下留白（见 09），
   这是"照片居中、两侧留黑"的取舍。
5. **设置页的信息架构**：连接、等待时长、本地存储三段，加上折叠的高级。
   是否有更合适的组织方式。
6. **深色模式**：20–22 三张，重点看卡片边界与状态点在深色下是否还需要更明显。

## 复现方式

截图脚本在 `../../../tools/capture-ui*.ps1`，用 uiautomator 定位控件、adb 截图，
按 `01`→`22` 的顺序驱动同一台模拟器。样式令牌（颜色、字号、间距）以 `../../DESIGN.md` 的
「界面规范」一节与 `android/app/src/main/kotlin/dev/haljk/glow/ui/theme/Theme.kt` 为准。
